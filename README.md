# Weibo Reader

Weibo Reader 是一款适用于 macOS 的本地阅读工具。可以读取并保存某位微博用户发出和收到的评论、提及该用户的内容、该用户的微博，或专门保存一条微博下面的评论。保存后，可以离线搜索、生成 HTML 报告，也可以让应用按计划检查新评论。

本工具数据获取完全依赖于微博开放平台CLI服务。如果遇到问题，欢迎反馈。
